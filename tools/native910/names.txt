# 910 scripts carry no name tags, so names are curated here as the game is
# reverse-engineered (the Ghidra-naming workflow): pin a meaningful name to an
# important script and every dump renders its call sites as `~name();`.

# ids must exist in the pack — anything else fails the dump loudly.
